# Expense Analysis & Savings Recommendation (Excel)

**[View the project presentation (PDF)](nitin-expense-analysis.pdf)**

Analyzed 6 months of personal expense data in Excel using pivot tables and charts to find where the money goes and recommend how to increase savings.

## Tools Used
Microsoft Excel, Pivot Tables, Pivot Charts, Conditional Formatting (Data Bars), Filters

## Key Findings
- Grocery was the highest expense (Rs. 30,990 over 6 months)
- Shopping was the highest discretionary expense in June (Rs. 3,500)
- February was the costliest month (Rs. 15,620) due to a one-off trip

## Recommendations
- Cap discretionary shopping
- Plan big trips with a separate savings fund
- Reduce online food orders and dining out
- Budget groceries with a weekly list
